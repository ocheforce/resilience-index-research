# Funder Readiness

## What the repository demonstrates

The repository is designed to let a reviewer inspect the project before funding rather than rely on a pitch alone.

### Scientific case
- Defined research question.
- Explicit scientific boundaries.
- Prespecified pilot design.
- Scientific architecture.
- Statistical analysis plan.
- Reference-standard framework.
- Falsification criteria.

### Feasibility
- Pilot protocol.
- Six-month timeline.
- Three-tier budget with a recommended realistic tier.
- Risk management plan.
- Dissemination and impact plan.

### Reproducibility
- Version-controlled research documents.
- Deterministic scoring implementation.
- Automated tests for core transformations.
- Separation of research infrastructure from the older legacy computational prototype.
- No participant-identifying data in the repository.

## What a funder should not infer

The repository does not claim that:

- the Resilience Index is clinically validated;
- the score predicts disease, longevity, or burnout;
- the composite is superior to HRV;
- the candidate reference standards are all ready for production scoring;
- the pilot has already demonstrated an effect.

## Recommended funder-facing evidence chain

**1-page brief → Concept Note → Full Proposal → Scientific Architecture / Project Diagram → Pilot Protocol → SAP → Budget → Risk / Dissemination → GitHub → Landing Page**

The GitHub repository is supporting evidence for rigor and reproducibility; it is not a substitute for the grant application's scientific case, team, institutional pathway, ethics plan, or funder-specific requirements.

## Remaining infrastructure work

1. Verify and document every scoring reference parameter before it can enter production scoring.
2. Create a persistent archive/DOI for a stable release.
3. Keep the research-status page updated as validation milestones occur.
4. Prepare funder-specific application materials rather than sending the repository alone.

The repository now has a software licence, package metadata, a deterministic scoring engine, automated unit tests, a scientific project diagram, and a public research-status page.
