# Research Documentation

This directory contains the formal scientific and operational documentation for the Resilience Index pilot.

## Planned document groups

- `concept/` — concept note and full proposal
- `science/` — scientific architecture
- `protocol/` — pilot protocol
- `funding/` — budget
- `operations/` — timeline and risk management
- `dissemination/` — dissemination and impact plan

The finalized study documents will be added without changing the underlying scientific design.
