# Contributing

Resilience Index is an open biomedical research project.

Contributions should support scientific clarity, reproducibility, transparency, and responsible interpretation.

## Before contributing

- Read the current protocol and scientific architecture.
- Do not change prespecified study methods or analysis decisions without documenting the change.
- Clearly distinguish exploratory analyses from prespecified analyses.
- Do not introduce participant-identifying information.
- Do not make clinical, diagnostic, or predictive claims that are not supported by the study evidence.

## Research changes

Changes to the protocol, scoring system, primary outcome, primary analysis, or other prespecified elements should be documented in the changelog and version history.

## Code

Code contributions should be reproducible, readable, and accompanied by appropriate tests or documentation where practical.
