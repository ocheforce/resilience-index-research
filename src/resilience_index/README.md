# Resilience Index Analysis Package

This package will contain reusable functions for the Resilience Index scoring and analysis pipeline.

Planned modules include:

- reference normalization
- CRP transformation
- direction correction
- domain scoring
- composite scoring
- deficit calculation
- trapezoidal deficit-area calculation
- performance-change calculation
- missing-data handling
- statistical models
- validation and quality-control utilities

The implementation must follow the frozen pilot protocol and statistical analysis plan.
