# Research Status

**Project:** Resilience Index — Making recovery capacity measurable  
**Version:** v0.1  
**Stage:** Pre-pilot / protocol development

## What is complete

- Research question and scientific boundaries defined.
- Prospective single-arm observational pilot specified.
- Four-touchpoint Baseline → Acute → Peak → Recovery design specified.
- Pilot protocol v1.1 completed.
- Scientific architecture v1.1 completed.
- Statistical analysis plan established.
- Two prespecified composite weightings defined: RI_5050 and RI_6040.
- Primary outcome and falsification criteria specified.
- Pilot budget and six-month implementation timeline specified.
- Risk management and dissemination plans specified.
- Reference-standard framework and reference registry established.
- Public GitHub research repository established.
- Landing page established.
- Deterministic scoring-engine v0.1 implemented with automated tests.

## In progress

- Verification of candidate reference parameters for every scoring variable.
- Method/device/assay compatibility review for reference standards.
- Completion of institutional/ethics pathway.
- Recruitment and implementation partnerships.
- Final analysis-environment and dependency setup.
- Funding.

## Not yet established

The project does **not** yet have:

- prospective participant data;
- pilot-derived reference distributions;
- external validation;
- clinical validation;
- evidence that the composite outperforms HRV;
- evidence supporting disease, burnout, longevity, or treatment prediction.

## What funding unlocks

Funding enables the prospective pilot: institutional and ethics preparation, recruitment of approximately 120–150 participants to target ~100 completers, four measurement touchpoints, biomarker testing, cognitive and sport-performance assessment, statistical analysis, reporting, and dissemination/preprint preparation.

## Interpretation for reviewers

The project is currently a **well-specified research program awaiting prospective validation**, rather than a validated clinical product. The distinction is intentional: the current work makes the hypothesis, protocol, analysis, software, reference framework, and falsification criteria inspectable before participant recruitment.

The scoring engine is therefore an implementation of the prespecified analysis rules—not evidence that those rules are already clinically validated.
